# 마케팅 시뮬레이터 (Marketing Budget Simulator)

상시 운영 / CBT1 / CBT2 / 런칭 4개 구간으로 나눠 마케팅 액션 아이템(SNS·CRM, 영상 제작, 인플루언서, PR, 오프라인 행사 참여 등)을 관리하는 정적 HTML 예산 시뮬레이터입니다.

## 주요 기능

- 구간별 예산·예정일 입력 → 우선순위 기반 자동 추천으로 항목 구성
- 항목별 준비 소요기간(리드타임) 반영, "언제부터 준비를 시작해야 하는지" 자동 계산
- gamescom·지스타·The Game Awards처럼 고정 일정이 있는 행사는 항목 카드에서 실제 날짜 직접 입력
- 항목별 비용 부담 주체(퍼블리셔 / 개발사 / 공동 부담) 구분, 예산 진행률은 퍼블리셔·공동 부담분만 반영
- 항목별 예상 비용 직접 수정(커스텀 금액) 가능
- 선택한 전체 캠페인을 준비 시작일 → 실행일 막대로 보여주는 캘린더(간트 차트) 뷰
- 선택 상태·예산·날짜는 브라우저 로컬 스토리지에 저장(뷰어 개인 브라우저에만 저장, 서버 전송 없음)

## 사용 방법

`index.html`을 브라우저로 열거나, GitHub Pages로 배포된 주소로 접속하면 바로 사용할 수 있습니다. 별도 빌드 과정이나 서버가 필요 없는 순수 정적 페이지입니다.

## 주의사항

항목·금액·준비기간은 일반적인 콘솔·PC MMORPG 마케팅 관행을 기준으로 한 예시 추정치입니다. 실제 프로젝트에 적용하기 전 사내 예산 프로세스와 실제 견적으로 반드시 재검증하세요.
